## Descrizione

Progetto di un protocollo crittografico per il voto elettronico in ambiente universitario (rinnovo rappresentanze studentesche). Il sistema garantisce segretezza del voto, pseudo-anonimato, verificabilità individuale e universale, e resistenza alla coercizione, senza richiedere primitive avanzate come l'omomorfica o i mix-net.
